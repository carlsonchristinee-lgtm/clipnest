# ClipNest

Your personal clipboard library.

ClipNest helps you save, organize, search, and reuse:
- Text and notes
- Links
- Images
- AI prompts
- Social media captions and descriptions

## Features
- Organize clips by category and folder
- Search saved clips
- Copy clips with one tap
- Edit and delete saved clips
- Import and export backups

## Getting Started
Open index.html in a web browser.
